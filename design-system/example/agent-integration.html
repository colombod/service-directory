Agent integration

Point an Amplifier agent at this node's HTTP API. Nothing here is a capability the API doesn't already expose — the integration exists so connection setup happens once, in one place, instead of every consumer re-deriving it.

This node does not depend on Amplifier. It never imports it and behaves identically whether or not Amplifier is installed. Install the behavior bundle in your own Amplifier app configuration — not into this server.

    Add the behavior to your bundle

    App-level, alongside the rest of your Amplifier setup.

    includes:
  - bundle: git+https://github.com/microsoft/amplifier-foundation@main
  - bundle: git+https://github.com/<org>/amplifier-bundle-registry@main

    Or try it standalone before wiring it in:

    amplifier run --bundle git+https://github.com/<org>/amplifier-bundle-registry@main \
  "list the services on my registry"
  2. 2

    Three values, resolved once

    The same three a hand-written client would need. Copy them from here rather than reconstructing them by hand.

    Server URL http://100.111.191.22:80
    Env: REGISTRY_URL. Prefer the tailnet DNS name so any device on the tailnet resolves it.
    Write token ••••••••••••
    Required for every mutation. Not needed at all when the agent runs on this host — socket-level 127.0.0.1/::1 bypasses auth.
    CA certificate not applicable — this node is served over HTTP
    TLS instances only, and only those using the CA method.
  3. 3

    If this node is served over TLS

    curl -sk "$REGISTRY_URL/api/ca" -o registry-ca.crt
    Fetch the CA, never the leaf. The leaf is what the server presents on the wire; verifying against it fails with unable to get local issuer certificate.
    A 404 from /api/ca is an answer, not a fault. Under a publicly-trusted tailnet cert no CA file is needed; under a self-signed or local-CA tool there is nothing servable. The response body says which case you are in.
  4. 4

    Verify from the agent's side

    • ✓ Reads work — /api/services returned 14 entries across 2 origins.
    • ✓ Writes are authorised — a dry-run register returned 200, not a 403.
    • • Not yet checked: TLS trust. Only applies to a TLS-served node.
    A redirect to a login page is not a 401. An unauthenticated caller that gets a 3xx reads as unreachable to a probe. If a check fails with a redirect, the token is missing from the request, not wrong.
