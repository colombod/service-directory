Federation

Pair this node with another so each serves the union of both catalogues. Pairing is mutual and each direction mints its own per-peer token — revoking one peer never affects another.

Every action on this page mutates state and sends the write token from Write token. Browsing from the node itself (127.0.0.1) uses the localhost bypass instead, whatever is typed there.
  1. ✓

    Enable federation on both nodes

    Read at process start, not hot-reloaded — restart or re-install each node after editing its config.

    federation:
  enabled: true
  name: "amplifier-srv-01"             # this node's origin name
  base_url: "http://100.111.191.22:80" # advertised to peers when pairing
  description: "Home lab tailnet node" # local self-description only
  role: "primary"                      # local self-description only
    this node: enabled amplifier-srv-01 · http://100.111.191.22:80
  2. 2

    Issue a code on the node being paired to

    One-time use, expires in 600 s. Issue it on the node you are pairing to, then redeem it from the other node.

    9f2a1c · 7b4e · d081 expires in 9m 12s
  3. 3

    Redeem it here

    Must actually route from this node. Prefer the Tailscale DNS name; if this page is HTTPS, the peer URL must be HTTPS too.
    Records each node in the other's trust store.
  4. 4

    Verify the catalogues actually merged

    A successful handshake only proves trust was established. An unreachable peer is silently omitted from the aggregate rather than raising an error, so the mesh counts as federated only when both of these hold on both nodes.
