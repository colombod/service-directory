Use `HeaderButton` when the control must read as a button: header actions, and the composer's Send.

```jsx
<HeaderButton variant="agent" title="Muxplex Agent -- powered by Amplifier Agent">Agent</HeaderButton>
<HeaderButton variant="commit">Send</HeaderButton>
```

The Amplifier mark is the ecosystem's shared identity asset — `assets/amplifier/amplifier-icon-32.png`, rendered at 16×16. Any Amplifier app that wants to say "powered by Amplifier" uses that exact file. Never redraw it, recolour it, or add a second copy.
